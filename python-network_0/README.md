# Python - Network #0

This project is part of the ALU Higher Level Programming curriculum. It
covers HTTP and how to make requests from the command line using cURL:
methods, headers, status codes, cookies and request bodies.

## Learning Objectives

* What a URL is and how to read one
* The scheme for an HTTP URL
* What a domain name and a sub-domain are
* How to define a port number in a URL
* What a query string is
* What HTTP requests, responses, headers and message bodies are
* What an HTTP request method is
* What an HTTP response status code is
* What an HTTP cookie is
* How to make a request with cURL

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* All scripts are tested on Ubuntu 20.04 LTS
* All Bash scripts are exactly 3 lines long
* The first line of every Bash script is `#!/bin/bash`
* The second line is a comment explaining what the script does
* All cURL commands use the `-s` (silent) option
* All files end with a new line and are executable

## Tasks

| File | Description |
| ---- | ----------- |
| `0-body_size.sh` | Displays the size of a response body in bytes |
| `1-body.sh` | Displays the body of a response with a 200 status code |
| `2-delete.sh` | Sends a DELETE request and displays the response body |
| `3-methods.sh` | Displays all HTTP methods a server accepts for a URL |
| `4-header.sh` | Sends a GET request with a custom header |
| `5-post_params.sh` | Sends a POST request with two parameters |
