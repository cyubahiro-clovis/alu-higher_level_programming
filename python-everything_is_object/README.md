# Python - Everything is Object

This project is part of the ALU Higher Level Programming curriculum. It
explores how Python handles objects in memory: identity, references,
aliasing, and the difference between mutable and immutable types.

## Learning Objectives

* What an object is, and how a class differs from an object or instance
* The difference between mutable and immutable objects
* What a reference, an assignment and an alias are
* How to know if two variables are identical or linked to the same object
* How to display a variable identifier with id()
* The built-in mutable types: list, dict, set, bytearray
* The built-in immutable types: int, float, complex, str, tuple,
  frozenset, bytes
* How Python passes variables to functions

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* Interpreted on Ubuntu 20.04 LTS using python3 (version 3.8.5)
* All files end with a new line
* Answer files contain only one line, with no shebang
* Python files start with `#!/usr/bin/python3` and are executable
* Code follows the `pycodestyle` style guide (version 2.7.*)

## Files

Answer files `0-answer.txt` through `28-answer.txt` hold one-line answers
about identity, equality, mutability and argument passing.
`19-copy_list.py` defines a function that returns a copy of a list.
